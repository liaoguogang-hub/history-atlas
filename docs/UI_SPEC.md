# 历史图鉴 — 界面与交互规格

> 本文档是 UI 实现的依据。所有页面列出的组件、字段、交互都对应到 `data/SCHEMA.md` 的数据字段。

## 0. 设计基调

参考用户提供的「中国历史（消歧义）」年表图：

- **马卡龙色块**为视觉主语言，每个时期一个柔和底色，块内深色文字
- **左侧脊柱列**：大时期（时代）纵向堆叠，中间用竖线 + `|` 表示时间连续
- **右侧嵌套列**：子时期色块按时间上下排列，块高按持续年数比例（但设上下限）
- 整体是**一棵可缩放的树**，不是普通的列表

App 保留这套视觉语言，同时解决静态图无法做的事：**点开、搜索、跳转、对比**。

**配色**：浅底 + 马卡龙色块 + 深墨色文字。不用纯黑，不用高饱和。
**字体**：中文系统字体（`FontFamily.Default`），标题加粗，正文行高 1.7 倍便于长文阅读。

## 2. 核心页面详解

### 2.1 年表总览（TimelineTreeScreen）— 复刻参考图

**布局**：整个年表是一棵**布局树**，用自定义 `Layout` 或嵌套 `Column` 实现。

```
┌──────────────────────────────────────────────┐
│  左脊柱(时代)      │  中列(朝代)  │ 右列(子时期) │
├──────────────────────────────────────────────┤
│  ┌────────┐        │  ┌──────────────────┐  │
│  │石器时代│        │  │ 旧石器时代       │  │  ← 淡青
│  │(起源)  │        │  ├──────────────┤  │
│  │  │     │        │  │  │中石器时代   │  │  ← 淡黄
│  │  │     │        │  │  │新石器时代   │  │  ← 淡粉
│  └────────┘        │  └──────────────┘  │
│  ┌────────┐        │  ┌──────────────────┐  │
│  │ 原史   │        │  │ 旧石器时代       │  │
│  │ 时代   │        │  ├──────────────┤  │
│  │  │     │        │  │  │铜石并用   │  │  ← 淡青
│  │  │     │        │  │  │夏 商      │  │  ← 淡绿
│  └────────┘        │  └──────────────┘  │
└──────────────────────────────────────────────┘
```

**实现要点**

1. **三列布局**
   - 列 1：顶层时期（时代）。宽约 96dp。显示竖排文字或两行折行（如「石器\n时代」）。
   - 列 2：顶层时期下的子时期。宽约 40% 剩余。
   - 列 3：子时期下的更细节点。若无三级则并入列 2。
   - 使用 `Row` + 三段 `Column`，每列独立 `verticalScroll`。

2. **色块**
   - `PeriodBlock`：圆角矩形，`colorKey` → 背景色；左上角标题（粗体），下方起止年份（次级色）。
   - 高度：按 `span = endYear - startYear` 的**平方根**映射到 `48dp..160dp` 区间（平方根是为了让短时期也可读，长时期不过分膨胀）。
   - 块之间 4dp 间距。

3. **脊柱连接线**
   - 列 1 块右侧画一条竖线，贯穿该时代所有子块的高度区间。
   - 竖线上在该时代的中点画一个小横杠，标注该时代的起止年（垂直排布的年份刻度）。

4. **点击**
   - 任意色块 → 跳 `period/{id}`。子块带 `parentId` 的可返回上一级。
   - 长按 → 弹出快捷菜单（查看关联事件 / 加入对比 / 复制年代）。

5. **交互**
   - 顶部年代范围滑块：拖动可过滤出「只看 1900–2000 年」等区间的时期。
   - 搜索框内联在顶栏，实时高亮匹配的色块。

### 2.2 时间轴（TimelineAxisScreen）

横向可缩放时间轴，是年表树的另一种视角。

- **双轴**：上轴为公元纪年，下轴为「距今年数」；公元前区域用不同底色。
- **刻度**：按缩放级别自动切换 `500年 / 200年 / 100年 / 20年 / 5年 / 1年`。
- **事件标记**：竖线 + 圆点，重要度 5 的大且带标签。点击弹出气泡卡片。
- **缩放**：
  - 双指捏合 → 缩放
  - 横向拖动 → 平移
  - 双击 → 放大一级
  - 使用 `Modifier.pointerInput` + `detectTransformGestures`
- **筛选**：顶部芯片选择分类（政治/军事/科技/…），可多选。

### 2.3 时期详情（PeriodDetailScreen）

- 顶部：`ColorKey` 大色块 banner + 时期名 + 别名 + 起止年份（醒目大字）
- 「概况」卡片组：疆域 / 都城 / 人口 / 文化（图标 + 文字）
- 「子时期」：横向滚动的色块卡片
- 「关键人物」：圆形首字头像横排，点击进人物页
- 「代表事件」：按时间排序的列表，每行 `日期 | 名称 | 分类徽章 | 重要度星`
- 「同期世界」（仅世界史 scope 且该时期有中国对应）：显示中国史同时期节点 —— 通过年份区间匹配计算，**无需额外数据字段**。

### 2.4 事件详情（EventDetailScreen）

- 顶部：分类徽章 + 重要度（5 颗星）+ 日期 + 地点
- 大标题
- 摘要卡（浅色底）
- 正文：`detail` 全文，首段不折叠，其余「展开全文」
- 「涉及人物」：横排头像
- 「相关事件」：同 `periodId` 且同 `category` 或共享人物，取前 8 条

### 2.5 人物详情（FigureDetailScreen）

- 顶部：圆形大头像（姓氏首字 + 身份色）、姓名（大字）、别名、`生卒` · `身份` · `所属时期`（可点）
- 简介
- 「生平」长文
- 「主要成就」：带勾选图标的列表
- 「名言」：引用卡片，竖线 + 楷体感觉（用斜体替代）
- 「相关事件」：时间轴样式的竖列，每条可点
- 「相关人物」：头像网格

### 2.6 搜索（SearchScreen）

- 顶部 `TextField`，实时过滤
- 分段结果：**时期 / 事件 / 人物**
- 匹配字段：name、alias、summary、tags、detail（事件）、biography（人物）
- 高亮命中关键词
- 无结果时给出建议（热门朝代 / 常用搜索词）

## 4. 数据→界面字段映射速查

| 界面元素 | 数据来源 |
|---|---|
| 时期色块背景 | `period.colorKey` → `ColorKeys` 映射，未知则哈希 fallback |
| 色块年份 | `period.startDateText` / `period.endDateText` |
| 时期概况行 | `period.territory` / `capital` / `population` / `culture` |
| 事件日期 | `event.dateText`；跨度条用 `event.year` → `event.yearEnd` |
| 事件分类徽章 | `event.category` → §5 枚举 |
| 重要度星 | `event.importance` (1–5) |
| 人物头像文字 | `figure.name` 首字 |
| 人物身份色 | `figure.role` → 哈希到一组身份色 |
| 人物生卒 | `figure.lifeText` |
| 名言卡 | `figure.quotes` |
| 成就列表 | `figure.achievements` |
| 相关事件/人物 | `figure.relatedEvents` / `figure.relatedFigures` |
| 搜索命中 | `name` / `alias` / `summary` / `tags` / `detail` / `biography` |

## 5. 边界与空态

- 数据未注入时：显示「内容数据未就绪」占位页（不是崩溃）
- 某时期无事件：显示「本时期暂无详细事件条目」
- 悬空引用：Repository 层过滤掉，界面不显示断链
- 人物无生卒年：显示「生卒不详」
- 事件无 `yearEnd`：时间轴上渲染为点而非条
